# Security and Privacy

## Project status

Personal Style & Colour Guide is an educational, bilingual demo. Its manual colour exploration results are suggestions for inspiration, not professional assessments or medical advice. Do not treat the project as a source of verified information about a person's health or identity.

## Personal information

- Do not enter confidential, identifying or otherwise sensitive information.
- The colour-family palette builder stores the visitor's custom palette in the current browser's local storage. This data can remain on the device until it is cleared through the browser's site-data controls or the feature itself.
- Avoid using the demo on a shared device if you do not want another person using the same browser profile to see locally stored palette data.
- The current version uses manual selections. Do not upload photographs or assume that the site performs image-based colour recognition.

## Reporting a vulnerability

Do not post exploitable security details in a public issue. Use GitHub's private vulnerability reporting feature for this repository if it is enabled. Otherwise, contact the maintainer privately through the contact options on the GitHub profile.

Include the affected page or file, steps to reproduce, expected and actual behaviour, and potential impact. Use synthetic examples and do not send personal photographs, profile answers or other private data in a report.

## Contributions

Use synthetic test data. Do not commit real personal profiles, photographs, browser storage exports, credentials, API keys or other private information.
